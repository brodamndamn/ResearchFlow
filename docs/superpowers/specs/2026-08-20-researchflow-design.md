# ResearchFlow 设计说明

ResearchFlow 是一个面向简历演示的中文深度研究 Agent，目标运行环境为 2 核 2 GB 服务器。前端使用 React 展示研究工作台，后端使用 FastAPI 和 LangGraph 编排可观察的“规划—搜索—证据—写作—校验”流程。

## 产品行为

- 匿名访客选择快速或深度研究，提交 10–300 字的研究主题。
- LangGraph 生成计划后暂停，访客可以修改研究重点和子问题，再确认继续。
- 快速模式使用 2 个查询和约 4 个来源；深度模式使用 4 个查询、6–8 个来源、最多一次补充搜索和一次引用修订。
- 报告统一使用中文 Markdown 和数字引用，保存 7 天后自动过期。
- 首页公开 3 个精选案例；匿名报告只能通过不可猜测的 ID 和当前浏览器的最近记录访问。

## 系统架构

- React、TypeScript、Vite、Tailwind CSS 前端部署在 `/research/`。
- FastAPI、SQLAlchemy、SQLite 后端只运行一个 Uvicorn worker。
- 业务数据和 LangGraph checkpoint 使用不同的 SQLite 文件。
- 进程内队列同时执行 1 个任务，最多等待 3 个任务。
- 搜索使用 Tavily；模型使用环境变量配置的 OpenAI 兼容接口，默认 `deepseek-v4-flash`。
- 快速模式关闭模型思考，深度模式开启模型思考。
- SSE 推送任务快照和进度，REST 接口负责命令、恢复和报告读取。

## 安全与运维

- 生产环境按来源 IP 哈希限制每天快速 3 次、深度 1 次；开发环境只有真实回环客户端可以绕过。
- 只信任明确配置的本机反向代理传递的客户端地址。
- 来源正文属于不可信提示数据；Markdown 禁止原始 HTML 和不安全 URL 协议。
- 快速任务总超时 90 秒，深度任务总超时 180 秒；可重试的外部服务错误最多重试 2 次。
- systemd 运行后端，宿主机 Nginx 托管前端并代理 API 与 SSE。
