# ResearchFlow 日间／夜间主题切换设计

## 目标

为 ResearchFlow 增加全站日间／夜间主题切换。现有深色主题保留为默认夜间模式；用户选择日间模式后，刷新页面仍保持选择。

## 范围

- 在导航栏操作区加入图标按钮，位于返回与主页按钮之前。
- 夜间模式按钮显示月亮，点击切换到日间；日间模式显示太阳，点击切换到夜间。
- 主题状态仅保存在当前浏览器的 `localStorage`，键名为 `researchflow:theme`。
- 首次访问、无效存储值或存储不可用时使用夜间模式。
- 日间模式使用浅灰蓝背景、白色卡片、深蓝文字，品牌青色继续用于重点与交互。

## 架构

`Shell` 是唯一主题状态所有者：初始化时读取保存值，切换时更新 React 状态和 `localStorage`。根 `.app-shell` 设置 `data-theme` 属性，所有页面从 CSS 自定义属性取得颜色。

现有深色变量保留在默认 `:root`。`[data-theme="light"]` 覆盖背景、面板、边框、主要文字、弱文字及阴影相关变量；组件现有颜色逐步收敛到这些变量，不新增 UI 框架或依赖。

## 可访问性与响应式

- 按钮使用 `aria-label` 与 `title` 说明下一次操作。
- 使用 `aria-pressed` 暴露当前是否为日间模式。
- 图标按钮沿用现有导航按钮尺寸与窄屏隐藏文字的规则，手机端不挤占返回和主页按钮。
- 按钮拥有键盘焦点样式，日间模式维持足够的文字与边框对比度。

## 测试与验收

- 默认渲染夜间模式和月亮图标。
- 点击按钮后切换为日间模式、显示太阳图标，并写入本地存储。
- 重新挂载应用后从本地存储恢复日间模式；无效值回退夜间模式。
- 首页、工作台、报告页均使用同一个根主题属性。
- 前端单元测试、类型检查和生产构建通过。
